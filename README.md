# generators - মেসার্স শামীম মেশিনারিজ (Shamim Machineries)

মেসার্স শামীম মেশিনারিজ - জেনারেটর বিক্রয় ও সেবা কেন্দ্র (Vite + React + Tailwind CSS Web Application with Live Admin Panel).

## Key Features
- **Hero & Branding**: Full-width HD generator background banner with CTAs and feature tags.
- **Product Catalog**: Soundproof canopy and portable diesel generators with detailed specifications modal.
- **Admin Panel**: Live content management for products, team members, contact details, corporate client projects, and customer inquiries (`/admin`).
- **Corporate Projects**: Showcase of major client deployments (Square Pharma, Beximco, United Hospital, PRAN-RFL, Jamuna Future Park, City Group).
- **Team & Founder**: Profile section for proprietor and technical service team.
- **Floating Contact**: Quick WhatsApp and direct call floating action buttons.

## Tech Stack
- React 18 + Vite 6
- Tailwind CSS 4
- Lucide React & Framer Motion
